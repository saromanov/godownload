# Security policy

## Supported versions

Only the latest minor release receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security vulnerabilities.

Report privately via [GitHub Security Advisories](https://github.com/saromanov/godownload/security/advisories/new)
("Report a vulnerability"). Include a description, reproduction steps and the affected version.

You can expect an initial response within 7 days. Fixes are released as soon as practical, and you will be credited in the release notes unless you prefer otherwise.

## Scope

- Vulnerabilities in the godownload library itself.
- Out of scope: vulnerabilities in servers a user chooses to download from, or in applications that embed the library.
